# Java Library Management System

A console-based Library Management System developed using Java
and Object-Oriented Programming principles.

## Project Overview

This application manages books, users, borrowing periods,
reservations, and transaction history.

The system uses text-file storage to maintain data after
the application is closed.

## Features

- Admin and User login
- Book search
- Add, update and delete books
- User account management
- Borrow and return books
- Book reservation
- Multiple-copy management
- Date availability checking
- Collision handling
- Earliest available date suggestion
- Transaction history
- File-based data persistence

## Technologies

- Java
- Object-Oriented Programming
- ArrayList
- File I/O
- Exception Handling
- Date validation

## System Design

The application separates:

- User management
- Book management
- Transaction management
- File management
- Date validation
